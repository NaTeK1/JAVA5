  Phase 5 : Services + DAOs (45 min)

  Structure :
  src/main/java/com/example/[service]/dao/
  src/main/java/com/example/[service]/service/

  DAO (Data Access Object) :
  @Component
  public class EvenementDAO {

      @Autowired
      private EvenementRepository repository;

      public List<Evenement> findAll() {
          return repository.findAll();
      }

      public Optional<Evenement> findById(Long id) {
          return repository.findById(id);
      }

      public Evenement save(Evenement evenement) {
          return repository.save(evenement);
      }

      public void deleteById(Long id) {
          repository.deleteById(id);
      }
  }

  Service (Logique métier) :
  @Service
  public class EvenementService {

      @Autowired
      private EvenementDAO evenementDAO;

      @Autowired
      private CategorieDAO categorieDAO;

      public List<EvenementDTO> getAllEvenements() {
          return evenementDAO.findAll()
              .stream()
              .map(Evenement::toDTO)
              .collect(Collectors.toList());
      }

      public EvenementDTO getEvenementById(Long id) {
          Evenement evenement = evenementDAO.findById(id)
              .orElseThrow(() -> new
  ResourceNotFoundException("Événement non trouvé"));
          return evenement.toDTO();
      }

      public EvenementDTO createEvenement(EvenementDTO dto) {
          Categorie categorie =
  categorieDAO.findById(dto.getCategorieId())
              .orElseThrow(() -> new
  ResourceNotFoundException("Catégorie non trouvée"));

          Evenement evenement = Evenement.fromDTO(dto, categorie);
          evenement.setPlacesDisponibles(evenement.getPlacesMax());

          return evenementDAO.save(evenement).toDTO();
      }

      public EvenementDTO decrementerPlaces(Long id, Integer nbPlaces) {
          Evenement evenement = evenementDAO.findById(id)
              .orElseThrow(() -> new
  ResourceNotFoundException("Événement non trouvé"));

          if (evenement.getPlacesDisponibles() < nbPlaces) {
              throw new InsufficientPlacesException("Places
  insuffisantes");
          }


  evenement.setPlacesDisponibles(evenement.getPlacesDisponibles() -
  nbPlaces);
          return evenementDAO.save(evenement).toDTO();
      }
  }

  Structure :
  src/main/java/com/example/[service]/controller/

  Exemple :
  @RestController
  @RequestMapping("/api/evenements")
  public class EvenementController {

      @Autowired
      private EvenementService service;

      @GetMapping
      public ResponseEntity<List<EvenementDTO>> getAll() {
          return ResponseEntity.ok(service.getAllEvenements());
      }

      @GetMapping("/{id}")
      public ResponseEntity<EvenementDTO> getById(@PathVariable Long id)
   {
          return ResponseEntity.ok(service.getEvenementById(id));
      }

      @PostMapping
      public ResponseEntity<EvenementDTO> create(@Valid @RequestBody
  EvenementDTO dto) {
          return ResponseEntity.status(HttpStatus.CREATED)
              .body(service.createEvenement(dto));
      }

      @PutMapping("/{id}/decrementer-places")
      public ResponseEntity<EvenementDTO> decrementerPlaces(
          @PathVariable Long id,
          @RequestParam Integer nbPlaces) {
          return ResponseEntity.ok(service.decrementerPlaces(id,
  nbPlaces));
      }

      @DeleteMapping("/{id}")
      public ResponseEntity<Void> delete(@PathVariable Long id) {
          service.deleteEvenement(id);
          return ResponseEntity.noContent().build();
      }
  }

  Phase 7 : Communication REST (30 min)

  Dans le service qui doit appeler l'autre :

  1. Ajouter WebClient au pom.xml :
  <dependency>
      <groupId>org.springframework.boot</groupId>
      <artifactId>spring-boot-starter-webflux</artifactId>
  </dependency>

  2. Créer une classe client :
  @Component
  public class EvenementClient {

      private final WebClient webClient;

      public EvenementClient() {
          this.webClient = WebClient.builder()
              .baseUrl("http://localhost:8081")
              .build();
      }

      public EvenementDTO decrementerPlaces(Long evenementId, Integer
  nbPlaces) {
          return webClient.put()

  .uri("/api/evenements/{id}/decrementer-places?nbPlaces={nb}",
                   evenementId, nbPlaces)
              .retrieve()
              .bodyToMono(EvenementDTO.class)
              .block();
      }
  }

  Phase 8 : Gestion des exceptions (15 min)

  Créer les exceptions personnalisées :
  public class ResourceNotFoundException extends RuntimeException {
      public ResourceNotFoundException(String message) {
          super(message);
      }
  }

  public class InsufficientPlacesException extends RuntimeException {
      public InsufficientPlacesException(String message) {
          super(message);
      }
  }

  Handler global :
  @RestControllerAdvice
  public class GlobalExceptionHandler {

      @ExceptionHandler(ResourceNotFoundException.class)
      public ResponseEntity<ErrorResponse>
  handleNotFound(ResourceNotFoundException ex) {
          ErrorResponse error = new ErrorResponse(
              HttpStatus.NOT_FOUND.value(),
              ex.getMessage(),
              LocalDateTime.now()
          );
          return
  ResponseEntity.status(HttpStatus.NOT_FOUND).body(error);
      }

      @ExceptionHandler(MethodArgumentNotValidException.class)
      public ResponseEntity<ErrorResponse>
  handleValidation(MethodArgumentNotValidException ex) {
          String message = ex.getBindingResult()
              .getFieldErrors()
              .stream()
              .map(FieldError::getDefaultMessage)
              .collect(Collectors.joining(", "));

          ErrorResponse error = new ErrorResponse(
              HttpStatus.BAD_REQUEST.value(),
              message,
              LocalDateTime.now()
          );
          return ResponseEntity.badRequest().body(error);
      }
  }

  Conseils Stratégiques

  1. Commencez TOUJOURS par les entités - c'est la base
  2. Testez fréquemment - démarrez l'application toutes les 20 minutes
  3. Ne perdez pas de temps sur les tests si vous manquez de temps -
  priorisez les fonctionnalités
  4. Communication REST en dernier - assurez-vous que chaque service
  fonctionne indépendamment d'abord
  5. Utilisez Lombok massivement pour gagner du temps
  6. Copiez-collez intelligemment - une fois une entité faite, les
  autres suivent le même pattern
